# HeartSpace - Global Emotional Support Platform

A comprehensive web application designed to provide emotional support, mental wellness tools, and peer support services in a safe, anonymous environment.

## 🌟 Features

### Core Features
- **Anonymous Chat Support** - Connect with trained listeners and peer supporters
- **Wellness Tools** - Breathing exercises, meditation timer, and stress relief techniques
- **Private Journal** - Secure, encrypted personal journaling space
- **Crisis Support** - Immediate help and resources for urgent situations
- **Mental Health Resources** - Educational content and self-help materials

### New Features (Latest Update)
- **User Authentication** - Secure sign-up and login system
- **Peer Support Application** - Training process for becoming a peer supporter
- **International Support** - Global coverage with 70+ countries supported
- **Cultural Sensitivity** - Multilingual and culturally appropriate support

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/kevinking-coder/hearts.git
cd hearts
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:3000`

## 🛠️ Tech Stack

- **Frontend**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router DOM

## 📱 Features Overview

### Authentication System
- User registration with email, name, and country
- Secure login/logout functionality
- Session management with localStorage

### Peer Support Application
- Comprehensive application form
- Interactive training assessment (5 questions)
- 80% passing score required
- Guidelines and resources for peer supporters

### International Support
- Support for 70+ countries
- 24/7 global coverage
- Cultural sensitivity training
- Multilingual support capabilities

### Chat System
- Four types of support:
  - Professional Support (AI)
  - Peer Support
  - Crisis Support
  - Self-Help Resources
- Anonymous and secure conversations

### Wellness Tools
- Breathing exercises with visual guides
- Meditation timer with ambient sounds
- Progressive muscle relaxation
- Stress relief techniques

## 🔒 Security & Privacy

- **Anonymous Support**: No personal information required for basic support
- **Secure Authentication**: Email-based registration with password protection
- **Data Privacy**: Local storage for user preferences and journal entries
- **Crisis Protocols**: Clear guidelines for handling emergency situations

## 🌍 International Features

- **Global Coverage**: Support available 24/7 across multiple time zones
- **Cultural Sensitivity**: Training for peer supporters on cultural awareness
- **Multilingual Support**: Framework for multiple language support
- **Country Selection**: 70+ countries available for user registration

## 📊 Peer Support Training

The peer support application includes a comprehensive training process:

1. **Application Form**: Personal information, experience, and motivation
2. **Training Assessment**: 5 questions covering:
   - Active listening and empathy
   - Crisis response protocols
   - Professional boundaries
   - Cultural sensitivity
   - Support conversation techniques
3. **Scoring System**: 80% passing score required
4. **Guidelines**: Clear protocols for peer supporters

## 🚀 Deployment

The application is built with Vite and can be deployed to any static hosting service:

```bash
npm run build
```

The built files will be in the `dist/` directory.
